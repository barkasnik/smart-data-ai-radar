# Changelog

## 0.3.0

- Added `weekly` and `monthly` intelligence modes.
- Added cadence-specific policy-priority weighting.
- Added Government/Smart Data PESTLE analysis.
- Added UK Smart Data programme SWOT analysis.
- Added urgency, impact, consequences, policy advancement, opportunity, monitoring need, strategic significance, implementation risk, novelty and evidence-strength scoring.
- Added controlled multi-hashtag classification including `#PolicyGap`, `#Opportunity`, `#Threat`, `#Monitor` and `#AIxSmartData`.
- Added humanised `bottom_line` and Government Smart Data interpretation fields.
- Added weekly/monthly synthesis sections for policy gaps, opportunities, threats and monitoring.
- Added separate weekly/monthly output files and analysis history in SQLite.
- Added GitHub Actions schedules for weekly and monthly briefings plus manual mode selection.
